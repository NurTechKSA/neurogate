Без подписки

Два уровня. «Старт» работает сразу и ничего не требует. «Прокачка» — когда бесплатных моделей OpenCode станет мало: свои личные лимиты и десятки нейросетей.

Уровень 1 · Старт

5 минут · без ключей · без терминала

Скачай приложение OpenCode

Бесплатная программа-агент. Похожа на чат Claude или ChatGPT, но сама пишет файлы в твоей папке и запускает команды.

↓ Скачать OpenCode

Mac: открой скачанный файл и перетащи OpenCode в «Программы».

Windows: запусти скачанный установщик. Если появится синее окно «Windows защитила компьютер» — «Подробнее» → «Выполнить в любом случае».

Открой папку проекта и выбери бесплатную модель

  • Создай пустую папку, например my-first-ai, и открой её в OpenCode.
  • Внизу окна нажми на название модели и выбери модель с пометкой Free — начни с DeepSeek V4.1 Flash Free.

Возьми 3 бесплатных ключа

Ключ — личный пропуск к нейросети. Каждый сервис выдаёт его бесплатно за пару минут, карта не нужна. Открой ссылку, войди и создай ключ:

Google Gemini ↗Google-аккаунт → «Create API key». Из РФ — с VPN.
OpenRouter ↗Вход через Google или GitHub → «Create Key».
NVIDIA NIM ↗Только почта → «Generate API Key».

Удобнее всего собрать ключи в боте: он даёт ссылки по очереди, проверяет каждый ключ и в конце выдаёт одну команду установки с твоими ключами. Хочешь ввести ключи сам — пропусти бота: установщик спросит их по очереди.

Открой терминал и вставь команду

Терминал: нажми ⌘ + Пробел, набери «Терминал», нажми Enter.

PowerShell: нажми Пуск, набери «PowerShell», нажми Enter (обычный, не «от имени администратора»).

Скопируй команду, вставь в терминал (⌘ + Vправый клик или Ctrl + V) и нажми Enter. Если брал ключи в боте — вставь команду из бота, в ней уже твои ключи.

curl -fsSL https://raw.githubusercontent.com/RYAZHAPOVILNUR/neurogate/main/install.sh | bash
irm https://raw.githubusercontent.com/RYAZHAPOVILNUR/neurogate/main/install.ps1 | iex
  • Установщик сам скачает всё нужное — 2–3 минуты.
  • Спросит ключи: Enter — открыть страницу сервиса, потом вставь ключ (на экране он не виден — так и надо) и снова Enter.
  • Mac может попросить поставить «инструменты разработчика» — соглашайся, это нормально.
  • В конце увидишь ACCESS GRANTED. Открой новое окно терминала.

Перезапусти OpenCode и выбери neurogate

Закрой OpenCode полностью (⌘ + Qкрестик и значок у часов) и открой снова. В списке моделей появится neurogate — выбери его. Теперь лимит кончился у одной нейросети — шлюз сам берёт следующую.

Проверить, что всё работает, — в новом окне терминала:

Все строки [ OK ] — готово. Есть [ FAIL ] — рядом написано, какой командой починить.

С подпиской: режим оркестратора

Для тех, у кого Claude Pro/Max или ChatGPT Plus. Работаешь как обычно в Claude Code или Codex — но лимит подписки уходит только на «мозги», а объёмную работу делают бесплатные модели. Лимита хватает в разы дольше.

1 · тыпишешь задачу в Claude Code или Codex, как обычно
2 · подпискаплатная модель дробит задачу на шаги и поручает их команде neurogate delegate
3 · бесплатныепишут код, а платная модель проверяет результат и принимает работу

Поставь neurogate

Те же шаги, что в уровне 2: 3 ключа и одна команда. Если уже ставил — пропусти этот шаг.

curl -fsSL https://raw.githubusercontent.com/RYAZHAPOVILNUR/neurogate/main/install.sh | bash
irm https://raw.githubusercontent.com/RYAZHAPOVILNUR/neurogate/main/install.ps1 | iex

Включи режим оркестратора

Одна команда в новом окне терминала — для всех проектов сразу. Она добавит правило в ~/.claude/CLAUDE.md (Claude Code) и ~/.codex/AGENTS.md (Codex), а песочнице Codex разрешит связь со шлюзом.

neurogate connect orchestrator --global

Только для одного проекта — запусти в его папке без --global. Перезапусти Claude Code или Codex, чтобы правило подхватилось.

Команды

Набираются в терминале из любой папки.

neurogate doctor
Проверить всё: что работает, что сломано и как починить.
neurogate setup
Добавить ключи — мастер со ссылками на каждый сервис.
neurogate keys
Какие ключи есть и живы ли они.
neurogate delegate "задача"
Поручить задачу бесплатному агенту — он сам правит файлы в текущей папке.
neurogate ask "вопрос"
Быстрый ответ бесплатной модели прямо в терминале.
claude-free
Claude Code целиком на бесплатных моделях (подписка не нужна).
codex-free
Codex на бесплатных моделях; обычный codex не меняется.
neurogate connect opencode
Заново подключить OpenCode, если neurogate пропал из списка моделей.
neurogate restart
Перезапустить шлюз.

Вопросы

Почему это бесплатно? Где подвох?

Компании дают бесплатный доступ к своим нейросетям, чтобы разработчики их пробовали. У каждой есть дневной лимит. neurogate держит связку из десятков таких сервисов: кончился лимит у одного — запрос сам уходит к следующему. Чем больше ключей, тем дольше без пауз.

Подвох один: бесплатные модели слабее топовых платных. Для учёбы и своих проектов их хватает.

«command not found: neurogate» или «не является командой»

Закрой терминал и открой новый — установщик прописал команды, их видят только новые окна.

Агент ответил ошибкой или долго думает

Запусти neurogate doctor — он скажет, что не так. Чаще всего кончились лимиты (добавь ключей: neurogate setup) или шлюз не запущен (neurogate restart).

В OpenCode нет neurogate в списке моделей

Выполни neurogate connect opencode и полностью закрой и открой OpenCode. Если OpenCode ставил уже после neurogate — это обязательно.

Сколько хватит бесплатных лимитов?

На «Старте» лимиты общие на всех пользователей OpenCode: на час-два учёбы в день обычно хватает, в часы пик бывает «перегружено». На «Прокачке» лимиты личные и складываются из всех твоих ключей. Добавить ещё ключей: neurogate setup.

Можно в приложении ChatGPT или в чате Claude?

Нет. В их чатах всегда работает модель самой компании и тратится твой тариф. Бесплатно — в OpenCode, claude-free, codex-free и в VS Code через расширение Cline (neurogate connect cline). С подпиской — режим оркестратора (путь B).

Мои ключи в безопасности?

Ключи живут только на твоём компьютере, в файле ~/neurogate/.env. Бот удаляет сообщение с ключом сразу после проверки, хранит ключи зашифрованными и отдаёт их один раз по твоему коду — после установки на сервере их нет.

Никому не пересылай ключи и код из бота. Один ключ на группу кончится за час, а сервис может заблокировать аккаунт.

Можно подключить GitHub, браузер, Notion — как коннекторы в ChatGPT?

Да. В OpenCode это MCP-серверы: opencode mcp add — и у агента появляются новые инструменты. Написать свой MCP-сервер — отличная задача для практики.

Бесплатные модели могут учиться на запросах. Не давай им личную и рабочую почту и секреты — только учебные данные.
