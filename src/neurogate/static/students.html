01КЛЮЧИ

Добудь ключи доступа в боте

Ключ — пропуск к нейросети, каждый сервис выдаёт свой бесплатно. Бот даёт ссылку, ты создаёшь ключ и присылаешь его в чат. Бот проверяет и сразу стирает сообщение. 3 ключа — минимум, 10–15 — режим «не упираюсь в лимиты».

02ВНЕДРЕНИЕ

Вставь команду из бота в терминал

Терминал нужен один раз. Команду с секретным кодом выдаст бот — вставь её и нажми Enter. Дальше всё ставится само: шлюз, ключи, автозапуск, подключение к OpenCode.

Терминал: ⌘ + Пробел → напиши «Терминал» → Enter.

PowerShell: Пуск → напиши «PowerShell» → Enter.

Терминал: Ctrl + Alt + T.

Без бота тоже можно — ключи добавишь потом командой neurogate setup:

∞РАСТЯНИ

Подписка думает — бесплатные модели пашут

Работаешь в Codex или Claude Code, но лимита подписки не хватает? Включи режим оркестратора: платная модель составляет план и проверяет результат, а код пишут бесплатные модели через neurogate. Лимит подписки уходит только на «мозги».

  • Нужен уровень 2 (neurogate установлен).
  • В папке проекта выполни команду ниже — она добавит инструкцию в AGENTS.md (Codex) и CLAUDE.md (Claude Code).
  • Для всех проектов сразу: neurogate connect orchestrator --global.
neurogate connect orchestrator

Codex запускает команды в песочнице без сети — разреши ему выход на 127.0.0.1, когда он спросит, или навсегда: в ~/.codex/config.toml секция [sandbox_workspace_write], network_access = true.

> DEBUG LOG

Почему это бесплатно? Где подвох?

Компании дают бесплатный доступ к своим нейросетям, чтобы разработчики их пробовали. У каждой есть дневной лимит. neurogate держит связку из 50 таких сервисов: кончился лимит у одного — запрос сам уходит к следующему. Поэтому чем больше ключей, тем дольше ты не упираешься в потолок.

Подвох один: бесплатные модели слабее платных топовых. Для учёбы и пет-проектов их хватает.

Насколько хватит бесплатных лимитов?

На уровне 1 лимиты общие на всех пользователей OpenCode и точных цифр нет: для учёбы по час-два в день обычно хватает, в часы пик бывает «перегружено». На уровне 2 лимиты личные и складываются из всех твоих ключей — чем больше ключей, тем дольше без пауз.

Можно подключить почту, Google, GitHub — как коннекторы в ChatGPT?

Да. В OpenCode это MCP-серверы: opencode mcp add — и у агента появляются новые инструменты (Gmail, Календарь, GitHub, Notion, браузер). Можно написать свой MCP-сервер — отличная задача для практики.

Бесплатные модели могут учиться на запросах. Не подключай личную и рабочую почту — только учебную.

Мои ключи в безопасности?

Бот удаляет сообщение с ключом сразу после проверки. Ключи хранятся зашифрованными и расшифровываются только твоим одноразовым кодом. Как только установщик их забрал — на сервере их нет. Дальше ключи живут только на твоём компьютере.

Никому не пересылай свои ключи и код из бота. Один ключ на группу кончится за час.

Можно в ChatGPT или в приложении Claude?

Нет. В их чатах всегда работает модель самой компании и тратится твой тариф. Бесплатно — в OpenCode, в claude-free, в codex-free и в VS Code через расширение Cline (neurogate connect cline).

Агент ответил ошибкой или долго думает

Запусти neurogate doctor — он скажет, что не так. Чаще всего: кончились лимиты (добавь ключей: neurogate setup) или шлюз не запущен (neurogate restart).

«command not found: neurogate»

Закрой терминал и открой новый — установщик прописал команды, их видят только новые окна.
