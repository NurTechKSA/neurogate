# Установка neurogate — инструкция для ИИ-агента

> Этот файл написан для ИИ-агента (Claude Code, Cursor Agent, Cline, OpenCode и т.п.).
> Человек дал тебе ссылку на него и попросил «установи neurogate». Выполни шаги ниже
> по порядку, сам, не перекладывая работу на человека. Говори с ним по-русски и коротко.

**Что это.** neurogate — локальный шлюз к ~50 бесплатным сервисам нейросетей. После
установки Claude Code и другие агенты работают на бесплатных моделях, без подписки.

## Правила

- **Ключи API ты не видишь и не вводишь.** Никогда не проси человека прислать ключ в этот
  чат и не читай файл `.env`. Ключи человек вставляет сам — в Telegram-бот или в мастер в
  своём терминале. Если ключ всё же попал в чат — не используй его и предложи создать новый.
- Ничего не устанавливай кроме того, что делает установщик ниже.
- Если шаг упал — покажи человеку последние строки вывода и что ты предлагаешь.

## Шаг 1. Есть ли код из Telegram-бота

Спроси: «Вы уже собрали ключи в Telegram-боте neurogate и получили код NG-…?»

- **Да** → попроси вставить только **код** (строка `NG-xxxxxxxx-…`). Код — не ключ, его можно
  передать тебе: он одноразовый и сгорает после установки.
- **Нет** → предложи: открыть бота и собрать ключи (5–10 минут), либо установить без ключей
  и добавить их позже мастером `neurogate setup` в своём терминале.

## Шаг 2. Установка

macOS / Linux (с кодом подставь его, без кода убери `NEUROGATE_CODE=…`):

```bash
curl -fsSL https://raw.githubusercontent.com/RYAZHAPOVILNUR/neurogate/main/install.sh | NEUROGATE_CODE=NG-... bash
```

Windows (PowerShell):

```powershell
$env:NEUROGATE_CODE="NG-..."; irm https://raw.githubusercontent.com/RYAZHAPOVILNUR/neurogate/main/install.ps1 | iex
```

Если ты не можешь дать человеку ввести данные в терминал (нет интерактивного ввода), а кода
нет — установщик сам пропустит мастер ключей. Тогда в конце попроси человека выполнить
`neurogate setup` в его терминале.

Установщик: ставит `uv` и Python 3.12, кладёт neurogate в `~/neurogate`, включает автозапуск
сервера, создаёт команды `neurogate` и `claude-free`, прописывает `~/.local/bin` в PATH.

## Шаг 3. Проверка

```bash
~/.local/bin/neurogate keys --offline
curl -s http://127.0.0.1:$(grep '^NEUROGATE_PORT=' ~/neurogate/.env | cut -d= -f2)/health
```

Ожидается `{"ok":true}` и хотя бы один ключ. Если ключей 0 — попроси человека выполнить
`neurogate setup` в своём терминале (не в этом чате).

## Шаг 4. Подключить агента к neurogate

| Агент | Что сделать |
|---|---|
| **Claude Code** | Ничего настраивать не надо: человек запускает `claude-free` вместо `claude` (в новом окне терминала). Обычный `claude` остаётся как был. |
| **Cline / Roo Code / Kilo Code** | Выполни `neurogate connect cline` и впиши показанные Base URL, API Key и модель `code` в настройки провайдера «OpenAI Compatible». |
| **Continue** | `neurogate connect continue` → добавь модель в `config.yaml` Continue. |
| **OpenCode** | `neurogate connect opencode` → провайдер в `opencode.json`. |
| **Cursor** | Cursor ходит к моделям со своих серверов и не видит localhost — нужен внешний адрес (VPS или туннель). Скажи об этом человеку. |
| **Codex CLI** | Пока не поддерживается (нужен Responses API). Предложи Claude Code через `claude-free`. |
| **ChatGPT / claude.ai в браузере** | Невозможно: модель там не меняется. Объясни это человеку. |

Модели neurogate: `code` — основная для кода, `code_fast` — быстрые правки, `auto` — сам
выберет, `chat` — тексты и вопросы.

## Шаг 5. Итог человеку

Скажи коротко: что установлено, сколько ключей, какой командой запускать (`claude-free`),
и что больше ключей — меньше пауз из-за лимитов (`neurogate setup` или снова бот).
